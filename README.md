# Mac 触控板（Mac Touchpad）

把安卓手机整块屏幕变成 Mac 的触控板：单指移动指针、轻点单击、长按拖拽、双指滚动、双指轻点右键，**三指可拖移也可快滑触发系统手势（调度中心 / 显示桌面 / 切换桌面），四指 / 五指按方向触发系统手势**。

连接方式：**USB 数据线 + ADB 端口转发**（延迟低、稳定），也支持 **WiFi 局域网直连**（同一 WiFi 下自动发现 Mac，无需数据线）。

---

## 项目结构

```
MacTouchpad/
  server.swift         Mac 端服务程序（Swift 单文件，无第三方依赖）
  touchpad-server      编译好的可执行文件（arm64）
AndroidTouchpad/       安卓端工程（Kotlin，Android Studio 可直接打开）
  app/src/main/java/com/mactouchpad/app/
    MainActivity.kt    主界面：全屏触控板 + 连接状态栏
    TouchpadView.kt    手势识别状态机（核心）
    ConnectionManager.kt  TCP 客户端 + 断线自动重连
    Protocol.kt         二进制协议编码
```

通信协议（TCP 5907 端口，大端序，每条消息 = 1 字节类型 + 载荷）：

| 类型 | 含义 | 载荷 |
|------|------|------|
| 0x01 | 移动指针（相对） | int16 dx, int16 dy |
| 0x02 / 0x03 | 左键按下 / 抬起 | 无 |
| 0x04 / 0x05 | 右键按下 / 抬起 | 无 |
| 0x06 | 滚动 | int16 dx, int16 dy |
| 0x07 | 系统手势 | int8 id（1=调度中心 2=上一桌面 3=下一桌面 4=显示桌面 5=启动台） |

## 一、Mac 端：编译并运行服务

已编译好的可执行文件在 `MacTouchpad/touchpad-server`，也可以自己编译：

```bash
cd MacTouchpad
swiftc -O -o touchpad-server server.swift
./touchpad-server
```

首次运行请授权**辅助功能**（否则模拟输入会被系统忽略）：

> 系统设置 → 隐私与安全性 → 辅助功能 → 勾选「终端」（如果从终端运行本程序）
> 或勾选编译出的 `touchpad-server` 可执行文件。授权后**重新运行**程序。

注意：macOS 的「屏幕共享」默认占用 5900 端口，本程序使用 **5907** 端口避开冲突。

## 二、手机端：安装 App

1. 用 Android Studio 打开 `AndroidTouchpad` 目录（首次 Sync 会自动下载 Gradle）。
2. 手机开启「开发者选项 → USB 调试」，用数据线连接 Mac。
3. 点击 Run 安装到手机（或 Build → Build APK 手动安装）。
4. 也可以直接安装仓库根目录预编译好的 `MacTouchpad-1.0-debug.apk`。

## 三、建立连接

### 方式 A：USB（推荐，延迟最低）

```bash
# 手机 USB 连上 Mac 后执行：
adb reverse tcp:5907 tcp:5907
```

然后打开手机上的 App，顶部状态显示「● 已连接 Mac 触控板」即可使用。
（`adb reverse` 在拔线后失效，重新插线后需再次执行；Mac 端服务保持运行即可。）

### 方式 B：WiFi（无需数据线）

1. 手机与 Mac 连接**同一个 WiFi**。
2. Mac 端服务启动时会打印本机局域网地址（如 `192.168.x.x:5907`），并广播 Bonjour 服务 `_mactouchpad._tcp`。
3. 若 macOS 防火墙开启，首次 WiFi 连接时允许 `touchpad-server` 接受传入连接。
4. 手机 App → 右上角 **⚙** → 连接方式选 **WiFi** → 点「自动发现 Mac」（自动搜到 Mac 并连接），或手动输入 Mac 的 IP 后点「连接」。

> 注意：App 的 WiFi 地址与连接方式会自动记忆，下次打开直接生效。
> WiFi 相比 USB 延迟略高，若感觉滑动卡顿，可在设置里适当调低指针灵敏度。

## 手势对照表

| 手机手势 | Mac 效果 |
|----------|----------|
| 单指滑动 | 移动指针（方向与手指一致） |
| 单指轻点 | 左键单击 |
| 单指长按 0.28 秒后滑动 | 按住左键拖拽（拖文件、选框、拖动窗口） |
| 双指滑动 | 滚动（自然滚动方向：手指上滑内容向上） |
| 双指轻点 | 右键单击 |
| **三指慢拖**（轻放后缓慢移动） | **按住左键拖拽**（拖窗口、选区 —— Apple 的 "Three finger drag"） |
| **三指快速滑动** | 系统手势：上滑→调度中心，下滑→显示桌面，左/右滑→切换桌面 |
| 四指上滑 | 启动台（Launchpad） |
| 四指下滑 | 显示桌面 |
| 四指 / 五指左滑 / 右滑 | 切换上一个 / 下一个桌面（全屏空间） |

> **三指快慢判别**：进入三指模式后观察约 250ms。
> - 若任一帧 centroid 速度超过 [swipeVelocityDpPerSec]（500 dp/s）→ 判为「快滑」，按方向派发系统手势。
> - 否则判为「慢拖」，按住左键跟随三指几何中心移动。
> 这与 Apple 在「系统设置 → 辅助功能 → 指针控制 → 触控板选项」中的「启用拖移」语义相同。
>
> **多指收尾的稳定性**：状态机会保持「多指」上下文直到最后一根手指抬起，
> 期间 3→2→1 的过渡不再误触发右键 / 滚动 / 拖拽。

> 系统手势通过 macOS 标准快捷键实现（调度中心 F3、显示桌面 F11、切换桌面 Ctrl+←/→、启动台打开 Launchpad）。若你的快捷键自定义过，可在「系统设置 → 键盘 → 键盘快捷键」中确认，或在 `server.swift` 的 `handleGesture` 中调整。

## 参数调节（按手感）

打开 `TouchpadView.kt` 顶部可调整：

| 参数 | 默认 | 说明 |
|------|------|------|
| `moveSensitivity` | 1.6 | 单指移动 → 指针位移倍数（越大指针动得越快） |
| `multiMoveScale` | 1.6 | 三指拖拽（centroid 移动）→ 指针位移倍数 |
| `scrollSensitivity` | 0.7 | 双指滚动倍数 |
| `longPressMs` | 280 | 长按进入拖拽的时长（毫秒） |
| `clickSlop` | 8dp | 点击判定最大位移 |
| `gestureSlop` | 50dp | 多指手势最小滑动距离（小于此值时不派发系统手势） |
| `swipeVelocityDpPerSec` | 500 dp/s | 三指判定为「快滑」的速度阈值 |
| `classifyWindowMs` | 250ms | 三指快慢滑判别观察窗口 |

## 屏幕方向适配

左上角有一个小圆形按钮，显示当前旋转角度（`0° / 90° / 180° / 270°`），点一下循环切换。
适用于手机握持方向与默认横屏不一致时（例如手机 home 键在右侧、平放在桌上反向使用等），
把触摸方向旋转到合适的角度即可。所有多指 / 长按 / centroid 都在 view 自己的坐标系里计算，
旋转只发生在 `onTouchEvent` 入口处把触摸坐标变换一次，不会影响手势识别。

## 常见问题

- **连不上 / 一直显示重连**：确认 Mac 端服务在运行（终端有「监听端口 5907」输出）；确认 `adb reverse tcp:5907 tcp:5907` 执行成功（可用 `adb reverse --list` 检查）。
- **指针不动，但连接正常**：辅助功能权限未授予，或授权后没有重启服务程序。
- **三指手势无反应**：先在 Mac 的「系统设置 → 键盘 → 键盘快捷键」确认调度中心（F3）/ 显示桌面（F11）快捷键未被修改。
- **三指拖拽误判成系统手势**（或反之）：调整 `swipeVelocityDpPerSec` 和 `classifyWindowMs`。慢拖调到更大阈值、更长窗口；快滑则调小。
- **滚动方向相反**：把 `TouchpadView.kt` 中 `Protocol.scroll` 的 `-dy` 改回 `dy`。
